🚕 TaxiRoute-SA

TaxiRoute-SA is a South African taxi route application designed to help users discover and navigate taxi routes more easily.

The project aims to make minibus taxi transportation more accessible by providing users with a simple way to explore routes, destinations, and relevant taxi information.

✨ Features

🗺️ Explore South African taxi routes

🚕 Find taxi routes between destinations

📍 View route and location information

🔎 Search for destinations and routes

📱 Responsive interface for desktop and mobile devices

⚡ Fast and modern web application

🎨 Clean user interface built with modern frontend technologies

🛠️ Technologies

TaxiRoute-SA is built using:

🚀 Getting Started
1. Clone the repository
git clone https://github.com/mulaloramagoma/TaxiRoute-SA.git

2. Navigate into the project
cd TaxiRoute-SA

3. Install dependencies
npm install

4. Start the development server
npm run dev


The application will be available at the local URL provided by Vite, usually:

http://localhost:5173

📦 Build for Production

To create a production build:

npm run build


To preview the production build locally:

npm run preview

🎯 Project Purpose

Public transportation is an important part of everyday life in South Africa. TaxiRoute-SA is intended to make finding and understanding minibus taxi routes easier through a digital platform.

The project can be expanded with additional route data, locations, taxi ranks, fares, schedules, and other useful transportation information.
